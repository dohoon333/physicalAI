# 컨베이어 트래킹 픽킹 연구 셀 MVP 의사결정·실행 보고서

| 항목 | 내용 |
| :--- | :--- |
| 상태 | PRD 기반 구현·측정 계획 |
| 목적 | 지연 보상이 이동 물체의 접촉 예측과 픽 성공에 미치는 효과를 단일 연구 셀에서 측정 |
| 결정 범위 | 단일 레인, 단일 물체, 단일 고정 빈의 4~6주 MVP |

## 요약 및 의사결정

승인 대상은 컨베이어를 멈추지 않고 X축 선행 이동과 Z축 흡착으로 단일 물체를 처리하는 연구 셀 MVP다. 핵심 판단은 과거의 유효 지연 표본만으로 보상한 조건이 동일한 보상 OFF 조건보다 나은지를 독립 기준 영상으로 판정하는 것이다. 본 문서는 구축 또는 성과 결과가 아니라, 구현 순서와 측정 게이트를 확정하는 계획이다.

## 선정된 MVP와 문제

물체 위치를 검출한 뒤 통신, 계산, X/Z 동작이 이어지는 동안 물체는 벨트 진행 방향으로 이동한다. MVP는 접촉 시각의 물체 중심을 예측해 X 명령을 만들고, X 도착 뒤 Z 하강, 진공 인가, 유지, 상승 순서로 수행한다. 기계적으로 고정한 `y_lane`만 사용하며, 카메라의 `y_cam`은 레인 적격성 확인용일 뿐 명령 축이 아니다.

레인 허용오차는 시작값 `|y_cam - y_lane| <= 5 mm`로 두고, 벗어남·경계 걸침·판정 불명은 `NO_PICK_LANE`으로 통과시킨다. 수동 가이드 레일은 물체의 횡방향 위치를 강제하고, X/Z 흡착은 벨트 방향과 높이만 제어한다.

## 폐루프와 인과적 지연 보상

각 프레임은 노출 시작 시각 `t0`의 위치 `s0`와 `encoder_count0`로 태깅한다. 명령 직전 `now = t_cmd_tx_pi`에서 현재 인코더 차이로 `s_est(now)`를 계산하고, 미래 접촉 위치는 현재 시점 뒤에 필요한 지연과 X/Z 동작 시간만 더해 산출한다.

`Pi`와 `ESP32`는 독립 단조 시계를 유지한다. 블록 시작 전 30회 교환으로 한정 affine clock mapping을 적합하며, p95 residual 2 ms 이하 및 최대 5 ms 이하일 때만 수락한다. 이후 5분마다 10회 교환으로 재확인한다. 원시 시각을 직접 빼지 않고, 수락된 mapping으로 환산한 물리 X 기동 시각만 사건 상관과 사후 지연 측정에 쓴다.

초기 `L_hat`은 계획된 지연 예산 실험으로 얻을 보수적 p95를 사용한다. 이후 `L_hat_k`는 완료된 과거 유효 시도의 관측 지연 `L_i`만으로 갱신하며, 현재 시도의 `L_k`와 미래 표본은 입력하지 않는다. 첫 20개 유효 표본은 warm up으로 표시해 KPI와 ablation 분모에서 제외한다. timestamp 무효, 인코더 불연속, mapping 부재, 수렴 실패는 추정값으로 보정하지 않고 정해진 `NO_PICK` 또는 무효 사유로 기록한다.

## MVP 범위와 제외 범위

포함 범위는 고정 조명, 단일 클래스, 단일 물체, IR 진입 태그, 인코더 태깅, X/Z 저전압 흡착, 단일 고정 빈, **순환 슈트와 계량 게이트**, 자동 원시 로그, 독립 기준 영상과 세션 분할 수동 주석이다. 보상 ON과 OFF는 같은 기구, 속도, 레인, 흡착 설정, 프로파일, 간격, 캘리브레이션, 안전 여유, 게이트를 유지하고 지연 보상 항만 다르게 둔다.

투입 간격을 ON/OFF 고정 조건으로 두려면 물체가 벨트에 오르는 방식이 정해져야 한다. 조건당 150개와 warm-up을 합치면 최소 340회 투입이 필요하고 무개입 30분 목표까지 있으므로, 수동 투입으로는 간격 고정과 표본 수를 동시에 만족할 수 없다. 따라서 배출 빈과 하류 회수 슈트를 벨트 진입부로 되돌리는 **중력 순환 경로**를 두고, 진입부에 **서보 계량 게이트**를 설치해 고정 주기 `T_release`로 한 개씩 방출한다. `T_release`는 `T_cycle_p95 + 20% margin` 이상으로 잡고 블록 시작 시 설정·로그하며 블록 중 변경하지 않는다. 게이트 통과 IR로 실제 방출 시각과 개수를 기록해 간격 고정이 지켜졌는지 검증하고, 중복 방출과 미방출은 `NO_PICK_SPACING` 또는 `FEED_FAULT`로 남긴다. 순환 물체는 10~20개로 하되 반복 사용에 따른 흡반 자국·마모는 블록마다 육안 점검하고 교체 이력을 기록한다. 시간 상관 편향은 block-randomized interleaving이 ON/OFF 간에서 상쇄한다.

Y축 액추에이터, 로봇팔, 동시 추적, 다중 클래스·등급·빈, 겹친 물체, 고속 라인, 상용 안전 인증, 생산 준비성은 제외한다. 이 MVP의 해석은 단일 레인·단일 물체·단일 빈 연구 셀에만 한정한다.

## 측정·KPI·독립 판정 계획

제어 카메라·압력·하류 카운터와 분리된 기준 영상 장치를 접촉 구간과 빈에 고정한다. 무작위로 섞인 `trial_id`를 보상 조건을 모르는 주석자가 판정하고, 접촉 프레임의 물체 중심과 흡반 중심으로 `e_contact`를 계산한다. 성공은 물체가 흡반과 함께 빈으로 이동해 빈 안에 정지했는지로 판정한다. 전체 적격 시도의 최소 20%는 재주석 또는 독립 주석으로 확인한다.

| KPI | 목표 또는 가설 | 판정 계획 |
| :--- | :--- | :--- |
| 픽 성공률 | 10 cm/s에서 90% 이상 목표 | 독립 판정 가능 적격 시도 중 기준 영상 `success` 비율 |
| 보상 효과 | OFF 대비 +50 percentage points 이상 가설 | ON과 OFF 성공률 차이 및 각 95% 신뢰구간 보고 |
| E2E 지연 | 150 ms 이하 목표 | 노출 시작부터 Pi의 X 기동 ACK 수신까지 median, p95, 최대값 보고 |
| 접촉 오차 | `abs(e_contact) <= 5 mm` 목표 | 기준 영상 주석의 median, p95, 5 mm 이내 비율. 부호 있는 median·평균도 함께 보고 |
| 유효 처리량 | 12 picks/min 이상 목표 | 기준 영상 `success` 수를 시험 벽시계 시간으로 나눈 값 |
| 무개입 가동 | 30분 이상 목표 | 수동 제거·재시작·축 이동 없이 지속한 시간과 안전 복구 횟수 |
| 표본 품질 | 조건당 독립 판정 가능 적격 시도 150개 이상, unscorable율 5% 이하 계획 | 조건별 `unscorable / (independently scorable + unscorable)`와 제외 사유를 별도 보고 |

`unscorable`은 영상 누락·손상, trial 연결 마커 부재, 필수 구간 완전 가림에만 사용한다. 압력과 하류 카운터는 진단 교차 확인이며 최종 성공률이나 접촉 오차의 단독 근거가 아니다.

주석은 자동화할 수 없는 별도 공수다. 1차 주석 대상이 340~400건, 20% 재주석을 포함하면 400~480건이며, 건당 접촉 프레임 탐색과 2점 마킹에 45~60초를 잡으면 **순수 주석 시간만 5~8시간**이다. 주석자 1명이 이를 연속 처리하면 후반부 판정 기준이 흔들리는 피로 드리프트가 생기고, 블라인드여도 이 드리프트는 제거되지 않는다. 따라서 1회 세션을 최대 60건 또는 60분으로 제한하고 세션 간 15분 이상 쉬며, 각 주석 레코드에 세션 ID와 세션 내 순번을 남긴다. 20% 재주석은 한곳에 몰지 않고 서로 다른 세션에 배치해 같은 `trial_id`의 1차·2차가 반드시 다른 세션에 속하게 한다. 재주석 쌍의 접촉 오차 차이를 세션 순번에 대해 보고 유의한 추세가 있으면 그 구간을 재주석한다. 주석 목록은 `trial_id` 기준 무작위 정렬하며 시간순·조건순 정렬을 금지한다. 주석이 끝나지 않은 조건의 KPI는 보고하지 않는다.

## 안전과 주요 리스크

ESP32가 결정론적 안전 상태 `BOOT`, `CALIBRATE`, `READY`, `TRACK`, `ARMED`, `PICK`, `VERIFY`, `RECOVER`, `FAULT_STOP`를 소유한다. Pi는 요청만 하며 E stop, 통신 상실, 제한 위반을 우회할 수 없다. 안전 정지는 X/Z 구동 차단, 진공 해제, 명령 거부를 수행하고 수동 원인 확인과 재캘리브레이션 뒤에만 재개한다.

주요 리스크는 레인 이탈, clock mapping 불수락, stale 프레임, 인코더 이상, 모션 지연, 압력 이상, 영상 판정 불가다. 이에 대해 새 픽 금지, 진공 없는 복귀, `FAULT_STOP`, 재캘리브레이션, 블록 무효화의 사전 정의된 반응을 적용한다. 모션·진공·복귀의 p95와 투입 간격이 측정되기 전에는 연속 픽 성능을 주장하지 않는다.

## MVP Go/No-Go 게이트

여섯 게이트가 모두 Go일 때만 결과를 해석한다. 하나라도 No Go이면 성공률 목표를 주장하지 않고 해당 원인부터 보완한다.

| 게이트 | Go 기준 | No Go 처리 |
| :--- | :--- | :--- |
| 물리 Y 레인 | 20개 acceptance check에서 모두 ±5 mm 이내, 레일 끼임 0건 | 레일 폭·중심 재조정 후 재확인 |
| 인과적 시각·clock mapping | mapping residual p95 2 ms 이하, 최대 5 ms 이하, 과거 유효 표본만으로 `L_hat` 산출 | 블록 무효화, timestamp·mapping 정책 보완 |
| 독립 ground truth | 기준 영상과 블라인드 주석으로 접촉·성공 판정, 조건별 unscorable 5% 이하 | 영상 배치·마커·주석 절차 보완 후 조건 재실험 |
| p95 모션·투입 예산과 no pick guard | X/Z/진공/복귀 p95와 속도별 간격 측정, 연속 픽은 `spacing_time >= T_cycle_p95 + 20% margin`일 때만 허용, 정량 guard·fault 전이 적용. 계량 게이트가 `T_release` 주기로 한 개씩 방출하고 통과 IR로 측정한 실제 간격 편차가 허용 범위 안 | 속도·간격·프로파일 축소 또는 기구 재조정. 중복·미방출 반복 시 게이트 재설계 |
| 고정 무작위 ON/OFF ablation | block randomized interleaving, 조건당 독립 판정 가능 적격 시도 150개 이상, 95% 신뢰구간 보고 | 조건 드리프트 제거 후 재실험 |
| 주석 무결성 | 400~480건 블라인드 주석이 세션 분할 규칙(최대 60건·60분)을 지켜 완료, 재주석 20%가 서로 다른 세션에 배치, 세션 순번 대비 유의한 드리프트 추세 없음 | 드리프트 구간 재주석. 주석 미완료 조건의 KPI는 보고하지 않음 |

## 4~6주 실행 로드맵

| 기간 | 실행 항목 | 완료 기준 |
| :--- | :--- | :--- |
| 1주차 | 사건 스키마, Pi·ESP32 분리 시계 로그, 지연 예산 사전 측정 | 원시 timestamp와 mapping 기록 경로 정의 |
| 2주차 | X/Z 기구, 고정 조명·레인, **순환 슈트·계량 게이트·통과 IR**, 인코더 거리 환산, 안전 상태 점검 | 물리 Y 레인 gate를 확인할 준비 완료 |
| 3주차 | 단일 클래스 검출, 레인 적격성, encoder tagging, 접촉 중심 예측, no pick 정책, **`T_release` 설정과 실제 간격 편차 측정** | 인과적 계획 레코드와 예외 사유 기록 |
| 4주차 | X/Z/진공/복귀 시퀀스, 기준 영상 배치와 동기 마커, **주석 도구·세션 로그 양식 완성** | 독립 판정 가능한 trial 데이터 흐름 확정 |
| 5주차 | 고정 조건의 block randomized ON/OFF 교차 실행 | 조건당 독립 판정 가능 적격 시도 150개 이상 확보 |
| 6주차 | **블라인드 주석 400~480건(5~8시간, 세션 분할)**, 재주석 20%와 드리프트 검출, 신뢰구간 보고 | 각 조건의 표본·unscorable·제외 사유를 포함한 측정 보고 |

5주차 실행과 6주차 주석을 분리한 이유는 주석이 자동화 불가능한 별도 공수이기 때문이다. 같은 주에 묶으면 주석이 밀리거나 세션 분할 규칙이 무너진다.

## 해석 경계와 다음 결정

측정이 완료되더라도 이 MVP는 과거 유효 지연 표본 기반 보상이 같은 조건에서 접촉 오차와 성공률에 미친 영향, 지연 예산의 분해와 변동, 단일 레인 조건의 속도·간격·안전 복구 한계만 판단한다. 상용 라인 처리량, 산업 안전 인증, 생산 환경 적합성, 다품종 분류 성능을 의미하지 않는다.

다음 결정은 여섯 게이트와 조건별 독립 판정 결과를 검토한 뒤 내린다. 모두 충족하면 별도 연구 질문과 안전·정답 데이터 설계를 전제로 동시 추적, 다중 등급, 다중 빈, 속도 매칭을 검토한다. 충족하지 못하면 확장 대신 실패한 게이트의 물리·시간·판정 절차를 먼저 수정한다.
