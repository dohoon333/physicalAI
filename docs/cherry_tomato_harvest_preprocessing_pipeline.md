# 방울토마토 수확 로봇 데이터 전처리 파이프라인 제안

> 대상: [robot_arm_pick_and_place_prd.md](./robot_arm_pick_and_place_prd.md) (v2), [cherry_tomato_harvest_field_survey_checklist.md](./cherry_tomato_harvest_field_survey_checklist.md)
> **개정 이력**: v2 — 로보틱스/CV 아키텍트 검토 결과를 반영해 (1) 세그멘테이션을 공통 단계로 이동하고 숙성도→파지 트랙을 직렬 게이트 구조로 수정, (2) 파지점과 절단점을 단일 결합 포즈로 재정의, (3) 색상 판별용 CLAHE 오남용 제거, (4) Super-resolution 기반 계측 주장을 근접 카메라 2단 촬영 방식으로 교체, (5) 체크리스트 신규/기존 항목(A-1·A-2·B-1~3·B-5·B-6·C-2·D-2·D-4·E-1·F-1~2·G-2·G-3·H-1·H-2)을 기법 목록에 반영, (6) 병원체 전파 등 리스크 추가.

본 문서는 아직 실제 현장 조사 응답이 채워지지 않은 상태에서, PRD 1.4/5.3에 기술된 **표준 온실 스펙(하이와이어 유인, 트러스 높이 0.5~2.2m, 통로 800~1,200mm, 과실 지름 15~30mm, 표준 6단계 숙성, Pedicel 절단 위치 등)과 6장 리스크 목록을 "베이스라인 현장 조건"으로 간주**하여 작성한 초안입니다. 실제 [cherry_tomato_harvest_field_survey_checklist.md](./cherry_tomato_harvest_field_survey_checklist.md) 조사 데이터를 채워 넣으면 임계값·필터 강도는 더 정밀하게 조정되어야 합니다.

> **용어**: 개별 과실을 연결하는 자루는 **Pedicel**(꼭지)이며, 화방 전체를 지지하는 주축은 Peduncle이다. 로봇이 절단하는 대상은 Pedicel이다.

## 1. 전처리 기법 목록

| 구분 | 기법 | 현장 조건 근거 |
| :--- | :--- | :--- |
| 공통 | Sensor Time Sync & Cross-registration (RGB-D ↔ 다분광) | 센서 조합 시 프레임/좌표 정합이 안 되면 이후 모든 단계가 어긋남 |
| 공통 | Color Calibration (ColorChecker 기준 화이트밸런스, 선형 노출/게인 정규화) | 온실 피복재(체크리스트 C-1: 유리/PE/경질판넬)별 광투과율이 달라 동일 숙성 단계도 색상값이 카메라마다 편차 발생. **주의**: 이 단계는 절대 색도를 보존해야 하므로 비선형 대비 확장(CLAHE 등)과 혼용하지 않음(4번 항목 참고) |
| 공통 | 보광 광원 스펙트럼 혼합 보정 | 체크리스트 C-2(보광 여부)에서 보조 LED 병행 시 광원 스펙트럼이 혼합되므로 광원 조합별 화이트 레퍼런스를 별도 등록 |
| 공통 | Specular Highlight 억제(편광 필터/다중노출 융합) | 방울토마토 표면 광택(A-6) 및 관수 직후 물방울(B-6)로 인한 하이라이트가 색상 기반 판별에 노이즈로 작용 |
| 공통 | Shadow Removal / Illumination Normalization | 잎에 의한 불규칙 그림자가 미숙과의 어두운 색과 혼동될 위험 |
| 공통 | Depth Hole-filling + Bilateral Filtering | 근접 촬영 거리(300~600mm)에서도 과실 곡면·잎 경계에서 Depth 결측 발생 |
| 공통 | 온실 구조물 Masking (지지대·유인끈·통로) | 로봇 작업반경 내 고정 장애물(체크리스트 E-3)을 사전에 ROI 밖으로 제거해야 후속 세그멘테이션 오탐 방지 |
| 공통 | Voxel Downsampling + Statistical Outlier Removal | 포인트클라우드 연산 부하를 Edge(Jetson) 수준에 맞게 경량화 |
| 공통 | **Instance Segmentation (YOLOv8-seg/FastSAM)** | 과실/잎/줄기/Pedicel 경계 분리는 숙성도 트랙(부위별 색상 샘플링)과 파지 트랙(포즈 추정) 모두가 공유하는 선행 조건이므로 Stage 0 말단의 공통 단계로 수행(2장 참조). SAM(ViT-H)은 연산량이 커 Edge 실시간 처리 대신 오프라인 정답 마스크 생성(라벨링)에만 사용 |
| 공통 | 이미지 비식별화(얼굴 블러링) | 체크리스트 H-1(작업자 접근 빈도)이 낮지 않은 현장에서는 수집 이미지 저장 전 얼굴 검출·블러링을 파이프라인에 필수 포함(PRD 5.1-7항) |
| 공통 | 렌즈 클리닝 트리거/열화 보정 | 체크리스트 D-4(렌즈 오염 위험)가 중간 이상이면 김서림/얼룩 열화 보정 필터와 정기 클리닝 스케줄을 결합 운용 |
| 숙성도 판별 | HSV/Lab 색공간 변환 및 정규화 | RGB보다 조명 변화에 강건한 색공간에서 표준 6단계 숙성 임계값 설정 |
| 숙성도 판별 | 품종별 색상 기준값 캘리브레이션 테이블 | 체크리스트 A-1(품종 구성)이 다품종 혼재인 경우 품종별로 발색 패턴이 달라 단일 임계값으로는 오판별 발생 |
| 숙성도 판별 | Multispectral Band Ratio(반사율 지표) 산출 | 근적외선 반사율로 숙성 진행도 보조 지표 확보(정량적 Brix 추정은 PRD상 Phase 2 초분광 과제로 분리) |
| 숙성도 판별 | Fruit 부위별 Multi-patch 색상 샘플링 + 다수결 판정 | 체크리스트 A-3(얼룩덜룩 발색 패턴) 품종은 평균색 1값만으론 오판별이 잦음 |
| 숙성도 판별 | 열과/변색/기형과 예외 클래스 필터 | 체크리스트 A-7(열과), A-8(기형과), H-2(방제 이력)에 해당하는 비정상 과실을 정상 숙성도 분류와 별도 클래스로 배제 |
| 파지·절단 결합 포즈 | 과실 크기 사전분포 기반 ROI/Anchor 설정 | 체크리스트 A-2(과실 크기 범위)에 따라 세그멘테이션 Anchor 및 그리퍼 개방 폭 캘리브레이션 기준이 달라짐 |
| 파지·절단 결합 포즈 | 구(Sphere) 피팅 기반 과실 중심 추정 | 방울토마토는 구형에 가까워 강체 부품용 GraspNet류보다 경량 구피팅이 Edge 연산에 유리(PRD 4장) |
| 파지·절단 결합 포즈 | Pedicel 축 방향 키포인트 회귀 | 과실 중심과 결합해 그리퍼-절단날 고정 오프셋을 적용할 단일 6-DOF 접근 포즈를 구성하는 핵심 입력(2장 다이어그램 참조) |
| 파지·절단 결합 포즈 | Occlusion 비율 추정 및 임계치 스킵 | 가림 비율이 높은 과실은 무리하게 포즈를 추정하지 않고 차기 순회로 넘김(포인트클라우드 완성 결과를 충돌맵에 직접 사용하지 않음, 3장 참고) |
| 파지·절단 결합 포즈 | 근접 정밀 카메라(D405급) 2단 촬영 | 광역 스캔(D435i)으로 대상을 확정한 뒤, 근접 정밀 카메라로 재촬영하여 절단 정밀도(±2mm) 확보 — Super-resolution 같은 생성적 기법으로 계측 정밀도를 확보하지 않음(3장 참고) |
| 파지·절단 결합 포즈 | Collision-aware 접근포즈 필터링 | 체크리스트 E-2(파지 여유 공간), E-3(장애물), B-1(유인방식), B-3(통로 폭) 기반 3D 충돌맵으로 접근 벡터 후보를 필터링 |
| 파지·절단 결합 포즈 | 이동 플랫폼 방식별 위치 보정 | 체크리스트 F-1(레일/AMR)에 따라 레일 인코더 오프셋 보정 또는 AMR 실시간 SLAM 보정 적용, F-2(위치 정밀도)가 낮으면 매 정지 시 비전 기반 재정합 추가 |
| 파지·절단 결합 포즈 | 엔드이펙터 구성별 접근 벡터 제약 | 체크리스트 E-1(그리퍼+절단 모듈 복합형 여부)에 따라 허용 접근각 범위가 달라짐 |

## 2. 전처리 파이프라인 (공통 → 숙성도 게이트 → 파지·절단 결합 트랙, 직렬 구조)

```
[Stage 0: 공통 전처리]
Sensor Sync → Color/Depth Calibration(선형) → Highlight/Shadow 제거 → 구조물 Masking
   → Denoising → Instance Segmentation(과실/잎/줄기/Pedicel 마스크 확정)
        │
        ▼
[Stage A: 숙성도 판별 게이트] (Stage 0의 세그멘테이션 마스크를 입력으로 사용)
HSV/Lab 변환 → 품종별 색상 기준 적용 → Multispectral Band Ratio →
부위별 Multi-patch 샘플링·다수결 판정 → 열과/변색/기형과 예외 필터
        │
        ▼  신뢰도 ≥90% & 목표 숙성 단계(라이트레드~레드)인 과실만 통과
   (미달/예외 → 재촬영 최대 2회 → 지속 미달 시 스킵, Stage B로 넘어가지 않음)
        │
        ▼
[Stage B: 파지·절단 결합 포즈 트랙] (통과한 과실에 한해서만 수행)
과실 크기 사전분포 기반 ROI 확정 → 구(Sphere) 피팅(과실 중심) → Pedicel 축 키포인트 회귀
→ 그리퍼-절단날 고정 오프셋 적용 → 단일 6-DOF 접근 포즈 산출
→ Occlusion 비율 임계치 검사(과도한 가림 시 스킵) → 근접 정밀 카메라(D405) 2단 재촬영
→ Collision-aware 접근포즈 필터링(인접 과실·구조물·이동플랫폼 위치 반영)
→ MoveIt2 궤적 생성 (잎/줄기 회피)
        │
        ▼
   [수확 실행: 그리퍼 접근 → grip force 제어 → 동일 접근축 상 Pedicel 절단]
```

**v1 대비 핵심 변경점**:
- 인스턴스 세그멘테이션을 Stage A/B 양쪽이 공유하는 Stage 0로 이동(기존에는 Stage B에만 있어 Stage A의 부위별 샘플링이 근거 마스크 없이 이뤄지는 모순이 있었음).
- Stage A와 B는 **병렬이 아니라 직렬**이다. 숙성도 미달 과실은 애초에 파지·절단 계획을 세울 필요가 없으므로, Stage A의 통과 여부가 Stage B 실행의 하드 게이트가 된다.
- "파지점"과 "절단점"을 더 이상 별도로 추정하지 않는다. 그리퍼와 절단날은 하나의 강체로 결합된 엔드이펙터이므로, 상대 오프셋은 하드웨어 상수이고 로봇이 실제로 추정해야 하는 것은 **과실 중심 위치 + Pedicel 축 방향** 하나뿐이다. 이 두 값에 고정 오프셋을 적용하면 단일 6-DOF 접근 포즈가 나온다.

## 3. 최고 리스크 항목과 완화 필터

| 순위 | 리스크 | 근거(PRD 6장 / 체크리스트) | 추가 전처리/필터 |
| :--- | :--- | :--- | :--- |
| 1 | **잎에 의한 가림(Occlusion)** | PRD 6장 최상위 리스크, 체크리스트 B-4(전정 수준) | 다중 시점 재촬영 트리거 + Occlusion 비율 추정 후 임계치 초과 시 스킵. **주의**: Point Cloud Completion으로 가려진 형상을 보완하더라도, 이 결과는 시각화·참고용으로만 쓰고 충돌맵(Collision Map)에는 직접 반영하지 않는다 — 완성 모델이 만들어낸 환각(hallucinated) 형상을 근거로 접근 경로를 계획하면 실제 충돌 위험이 있다. |
| 2 | **숙성도 오판별(불균일 발색·예외 과실 혼입)** | 체크리스트 A-3(불균일 발색), A-7(열과), A-8(기형과) | Multi-patch 샘플링 + 다수결 판정, 열과/기형과는 별도 예외 클래스로 분리, 경계값 근접 시 Human-in-the-loop 큐로 전환 |
| 3 | **파지/절단 중 손상 및 지연성 내상** | 체크리스트 A-4(밀집도), E-2(파지 여유공간), PRD 3장 손상률 KPI | 압력/슬립 센서 실시간 피드백 + Collision-aware 접근각 필터링. 즉시 표면 촬영만으로는 지연성 내상(멍)을 잡지 못하므로 48시간 후 표본 검사를 병행(PRD 3장) |
| 4 | **절단날을 통한 병원체(바이러스 등) 전파** | PRD 6장 신규 리스크 | 트러스 전환마다 절단부 소독 로그를 미션 데이터에 기록, 날 마모/오염 감지 시 자동 알림 — 전처리 파이프라인이 아닌 하드웨어 운영 절차이지만 수확 미션 데이터 모델(`harvest_mission_id`)에 소독 이력 필드로 연동 필요 |

## 4. 파지·절단 결합 포즈 모델 데이터 증강 전략

| 증강 기법 | 목적 | 적용 방식 |
| :--- | :--- | :--- |
| 합성 잎 가림 오버레이(Synthetic Leaf Occlusion) | Occlusion 강건성 확보 | Blender procedural plant로 생성한 잎 마스크를 실물/시뮬 이미지에 랜덤 비율(0~70%)로 오버레이 |
| 조명/계절 도메인 랜덤화 | 조도·색온도 변동 대응 | Isaac Sim에서 광원 색온도·강도를 계절/시간대 범위 내 랜덤 샘플링. 단, 숙성도 판별용 데이터셋에는 색도 자체를 왜곡하는 증강(과도한 Hue Jitter 등)을 적용하지 않는다 — 라벨(숙성 단계)의 근거가 색상이므로 색상을 왜곡하면 라벨과 이미지가 불일치하게 된다. |
| 밀집도 랜덤화(Cluster Density Randomization) | 밀집 트러스 대응 | 시뮬레이션 상 과실 간 거리·중첩 비율을 낮음~높음까지 균등 샘플링하여 학습 |
| Pedicel 굵기/각도 3D CAD 라이브러리 증강 | 품종별 Pedicel 형태 편차 대응 | 다양한 굵기·경도의 Pedicel CAD 모델을 결합 포즈 학습 데이터에 혼합 |
| 절단점 오프셋 증강(Cut Point Jitter) | 절단 정밀도 목표(±2mm) 강건화 | 정답 절단점 주변 ±1~3mm 범위 내 랜덤 오프셋 라벨을 추가해 경계 민감도 완화 |
| 부분 가림 크롭(Partial Occlusion Crop) | 실제 촬영 시 흔한 부분 가림 대응 | 학습 이미지의 20~50%를 랜덤 마스킹 후에도 동일 라벨 유지하도록 학습 |
| 기형과/열과 합성 증강 | 예외 클래스 데이터 부족 보완 | 실물 샘플이 적은 초기 단계에는 정상 과실 마스크에 균열·변형 텍스처를 합성해 예외 클래스 학습 데이터 확충 |
| Sim2Real Fine-tuning | 시뮬레이션-실물 격차 최소화 | 시뮬레이션 사전학습 후 실제 온실 소량 샘플(Few-shot)로 최종 미세조정 |

## 참고: 아키텍처 대안 (Phase 2 검토 항목)

본 문서는 PRD가 정의한 **개체(과실) 단위 수확** 아키텍처를 전제로 한다. 다만 트러스당 과실 수(10~30개)가 많고 개체 단위 사이클타임(목표 15초/개)의 누적 효과가 크므로, PRD 7장 로드맵의 Phase 2에서는 **트러스(화방) 단위 일괄 절단 수확**을 대안으로 검토하도록 남겨두었다. 트러스 단위 수확은 처리량 면에서 유리하지만 개체별 숙성도 등급 분류를 수확 이후 별도 선별 공정으로 이관해야 하는 트레이드오프가 있다. 본 전처리 파이프라인의 Stage 0(공통 전처리)·리스크 완화 기법 대부분은 두 아키텍처 모두에 재사용 가능하도록 설계되었다.
