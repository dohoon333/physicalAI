전이 학습과 파인튜닝

이미 검증된 가중치에서 시작하는 것이 왜 압도적으로 유리한가. 그리고 클래스 수가 달라도 대부분의 가중치가 그대로 넘어온다는 사실을 숫자로 확인합니다.

클래스 수가 달라도 백본은 그대로 온다

예외: SAR 위성영상·초음파·열화상처럼 픽셀 통계 자체가 자연 이미지와 다르면 스크래치를 검토할 수 있습니다. 다만 순서는 항상 파인튜닝 먼저입니다.

모델 크기는 작은 것부터

"성능 좋게 하려고 x 모델 씁니다"는 거의 항상 손해입니다. 큰 모델은 용량이 큰 그릇이고, 데이터가 그 그릇을 못 채우면 남는 용량으로 학습 데이터를 외웁니다.

모델 용량 대 데이터 양

정석은 n으로 시작 → 정체되면 s → 그다음 m. 크기를 올렸는데 성능이 안 오르면 문제는 모델이 아니라 데이터입니다.

상황별 선택: 두 개의 축

학생들이 가장 헷갈려하는 지점입니다. 데이터 양은 "얼마나 학습시켜도 되는가"를 정하고, 도메인 유사도는 "기존 특징이 쓸모 있는가"를 정합니다. 두 축이 독립이라는 걸 이해하면 표가 저절로 외워집니다.

상황 → 권장 프리징

두 축을 골라 보세요
상황권장근거

2단계 파인튜닝

데이터도 적고 도메인도 다른 최악의 경우, 두 축이 충돌합니다. 그때 나오는 답입니다. 뇌 MRI에는 COCO 이미지가 한 장도 없습니다. 흑백이고 질감도 다르고 "물체"의 개념 자체가 다릅니다.

여기서 전체를 한 번에 학습시키면 불안정해집니다. 헤드는 아직 아무것도 모르는 상태라 엉뚱한 그래디언트를 뿜는데, 그게 백본까지 흘러가 멀쩡하던 백본을 망가뜨립니다.

단일 단계 vs 2단계

개념 모형
Stage 1은 헤드를 진정시키는 단계입니다. 백본을 잠갔으니 헤드가 날뛰어도 안전합니다. 여기서 높은 성능을 기대하면 안 됩니다.
Stage 2는 백본까지 도메인에 맞추는 단계입니다. 헤드가 안정됐으니 풀어도 됩니다. 단 lr0=0.001 이하로 낮춰야 1단계 성과가 안 무너집니다.
비유

Stage 1은 통역사를 훈련시키는 것이고, Stage 2는 본인이 직접 그 언어를 배우기 시작하는 것입니다. 통역사 없이 바로 외국어를 배우려 하면 초반에 헤맵니다.

주의

데이터와 하드웨어에 따라 단일 단계가 이길 수도 있습니다. 2단계는 "항상 이기는 마법"이 아니라 도메인 격차가 클 때 학습 불안정을 줄이는 선택지입니다.
