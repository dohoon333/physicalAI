# [PRD] AI 비전 기반 방울토마토(Cherry Tomato) 자동 수확 Pick & Place 피지컬 AI 시스템

> **개정 이력**: v2 — 농업 도메인 전문가, 로보틱스/CV 아키텍트, 문서 정합성 검토 결과를 반영해 파지-절단 결합 구조, KPI 수치 정합성, 용어(Peduncle/Pedicel), 엔드이펙터 범위, 리스크 항목을 전면 수정.

---

## 1. 개요 및 문제 정의 (Overview & Problem Definition)

### 1.1 배경 및 작성 목적
본 문서(PRD)는 AI 비전 기술, 숙성도(Ripeness) 판별 알고리즘 및 6-DOF 파지·절단 결합 위치 추정(Grasp-Cut Pose Estimation) 알고리즘을 활용하여, 스마트팜/시설원예 온실 내 하이와이어(High-wire) 유인재배 방식으로 재배되는 **방울토마토를 자동으로 인식·숙성도 판별·파지·꼭지(Pedicel) 절단·등급별 적재**하는 **협동로봇 기반 농업용 Pick & Place 수확 시스템**의 제품 요구사항을 정의합니다.

본 시스템은 단순 산업 부품 Bin Picking과 달리, (1) 대상물이 살아있는 생물학적 개체로 개체마다 크기·색상·경도가 불균일하고, (2) 잎·줄기·인접 과실에 의한 상시적 가림(Occlusion)이 존재하며, (3) 파지 실패 시 상품가치 손상뿐 아니라 모주(母株) 손상으로 차기 수확량에 영향을 줄 수 있다는 점에서 **"피지컬 AI(Physical AI)"** 관점의 정밀 손상제어 및 적응형 인식이 핵심 기술 난제입니다. 또한 그리퍼와 절단날이 하나의 강체로 결합된 복합 엔드이펙터라는 점에서, 파지 위치와 절단 위치는 **독립적으로 추정할 수 없는 하나의 결합된 6-DOF 접근 포즈** 문제로 정의되어야 합니다(1.4절, 4장 참조).

### 1.2 기존 공정의 문제점
1. **인력 의존형 반복 수확 작업의 한계**
   - 트러스(화방)당 10~30개의 과실을 허리를 굽히거나 팔을 뻗은 자세로 반복 수확하여 작업자 요통·어깨 근골격계 질환(CTD) 증가, 수확철 성수기 인력난 및 이직률 급증.
2. **숙성도(당도) 판단의 개인차 및 비일관성**
   - 작업자별 숙성 판단 기준이 상이하여 미숙과(Green)·과숙과(Over-ripe)가 혼입 수확되고, 이는 선별 단계 재작업 및 등급 하락에 따른 매출 손실로 직결됨.
3. **비정형 생육 환경 대응 불가**
   - 과실이 트러스 단위로 군집(Cluster) 형성되며 잎·줄기·인접 과실에 의해 부분/완전 가림이 상시 발생하여, 기존 2D 비전 및 고정 지그 기반 자동화로는 개별 과실의 3차원 파지 위치 계산이 불가능함.
4. **손상 없는 정밀 파지·절단 실패**
   - 방울토마토는 표피가 얇고 내부 과육이 연하여 그리퍼 압력이 조금만 과해도 멍(Bruising)·파열이 발생하며, 꼭지(Pedicel, 개별 과실 자루) 절단 위치가 부정확하면 과실 손상뿐 아니라 다음 수확에 영향을 주는 모주(줄기) 손상으로 이어짐.
5. **연속적·비주기적 수확 타이밍 대응 필요**
   - 방울토마토는 동일 트러스 내에서도 과실별 숙성 속도가 달라 짧은 주기(2~3일)로 반복 순회 수확이 필요하며, 인력만으로는 최적 수확 타이밍을 놓쳐 로스(Loss)가 발생함.
6. **병해충·생리장해에 따른 손상·오염 혼입**
   - 열과(Cracking), 병해충(잿빛곰팡이병 등)에 의한 표면 변색·오염, 수분(受粉) 부족에 따른 기형과(Catface) 등이 혼입되면 비전 기반 숙성도 판별의 오탐 요인이 되며, 별도의 손상/오염 필터링 로직 없이는 상품성 낮은 과실이 정상과로 오분류될 수 있음.

### 1.4 대상 작물 및 재배 환경 스펙 (Crop & Environment Specification)

| 항목 | 스펙 |
| :--- | :--- |
| 재배 방식 | 하이와이어(High-wire) 유인재배, 단일 열(row) 기준 |
| 통로 폭 | 800~1,200mm (로봇/AMR 이동 통로) |
| 트러스(화방) 높이 범위 | 지면 기준 0.5m ~ 2.2m (생육 진행에 따라 상승) — 로봇 작업반경/이동 플랫폼 리프트 축 설계 시 이 전체 범위를 커버해야 함(4장 참조) |
| 트러스당 평균 과실 수 | 10~30개 (품종·재배 조건에 따라 편차 큼) |
| 과실 크기 | 지름 15~30mm (품종별 5~20g 소과종부터 20~30g 대추형까지 편차 존재 — 실제 도입 시 [현장 조사 체크리스트](./cherry_tomato_harvest_field_survey_checklist.md) A-1/A-2로 재확인 필요) |
| 과실 개당 무게 | 10~20g (참고치, 상동) |
| 숙성 단계 구분(표준 6단계) | 그린(Green) → 브레이커(Breaker) → 터닝(Turning) → 핑크(Pink) → 라이트레드(Light Red) → 레드(Red) |
| 수확 대상 숙성 단계 | 라이트레드 ~ 레드 (당도/경도 기준 설정값 이상) |
| 수확 제외 기준 | 과숙(Over-ripe, 표준 6단계 범위를 벗어나 수확 적기가 지난 상태) — 별도 예외 클래스로 분류, 표준 6단계에는 포함하지 않음 |
| 꼭지(Pedicel) 절단 위치 | 이층(Abscission Layer) 기준 과실 상단 5~10mm 지점(약 5mm 폭의 절단창) |

> **용어 구분(중요)**: **Peduncle**(화방 주축, 트러스 전체를 지지하는 줄기)과 **Pedicel**(개별 과실을 연결하는 자루/꼭지)은 서로 다른 부위다. 본 시스템이 로봇으로 절단하는 대상은 개별 과실의 **Pedicel**이며, 본 문서 전체에서 이 용어로 통일한다.

## 2. 사용자 시나리오 및 워크플로우 (User Scenarios & Workflow)

### 2.1 핵심 공정 프로세스 (Core Flow)
```
[1. 트러스 촬영/숙성도 판별] -> [2. 과실 중심 + Pedicel 축 기반 결합 6-DOF 접근 포즈 추정] -> [3. 잎/줄기 회피 접근 궤적 생성]
   -> [4. 소프트 그리퍼 접근 및 압력 제어 파지] -> [5. 동일 접근축 상에서 Pedicel 절단] -> [6. 손상 검사 및 등급별 트레이 적재]
   -> [7. 레일 구간 이동] -> [8. 잔여 미수확 과실 카운트 및 재순회 스케줄링]
```

1. **인식 단계**: RGB-D(광역 스캔용) + 컬러/다분광 카메라로 트러스 촬영 → 개별 과실 인스턴스 세그멘테이션 → 색상(적색도)/반사광 기반 숙성 단계 분류(표준 6단계).
2. **파지·절단 결합 포즈 추정 단계**: 수확 대상(라이트레드~레드) 과실에 한해 과실 중심 3D 위치와 Pedicel 축 방향을 추정하고, 그리퍼-절단날 간 **고정된 하드웨어 오프셋**을 적용해 단일 6-DOF 접근 포즈를 산출(파지점과 절단점을 별도로 추정하지 않음) → 잎/줄기/인접 과실 회피 경로 계산(MoveIt2).
3. **수확 실행 단계**: 근접 정밀 카메라로 재확인 후 소프트 그리퍼 접근 → 압력/슬립 센서 기반 grip force 실시간 제어(손상 방지) → 동일 접근축 상에서 가위형 엔드이펙터로 Pedicel 절단(또는 비틀어 따기 Twist-pick 대체 로직) → 절단 성공 여부 검증.
4. **검증 및 적재 단계**: 과실 표면 손상(멍·파열) 여부 촬영 확인(경미한 내상은 즉시 검출이 어려우므로 3장 KPI의 표본 검사 병행) → 숙성 등급/크기별 트레이 자동 분류 적재.
5. **이동 단계**: 레일/AMR 기반 다음 트러스 구간으로 이동 → 구간별 위치 좌표 갱신.
6. **재고/스케줄 관리 단계**: 미수확(미숙과·미탐지) 과실의 위치·숙성 예상 시점 기록 → 차기 순회 수확 스케줄에 반영.

## 3. 성공 지표 (Key Performance Indicators, KPI)

| KPI 항목 | 현재 기준 (As-Is) | 목표치 (To-Be) | 측정 방법 및 조건 |
| :--- | :--- | :--- | :--- |
| **수확 성공률 (시도 대비)** | 숙련 작업자 98% | **85% 이상** | `(성공 수확 개수 / 파지·절단 시도 개수) × 100` — 인식 자체에 실패해 시도조차 못한 과실은 아래 미탐지율로 별도 집계 |
| **1회 순회 미탐지율** | - | **15% 이하** | `(가림 등으로 인식 실패한 과실 수 / 전체 수확대상 과실 수) × 100` — 해당 과실은 차기 순회 대상으로 자동 기록 |
| **3일 누적 미수확율** | - | **10% 이하** | 재순회(최대 2~3회/주) 반영 후에도 최종 미수확 상태로 남은 과실 비율 |
| **과실 손상률 (Damage/Bruising Rate)** | 숙련 작업자 3% | **5% 이하** (Phase 2 목표: 3% 이하) | 수확 직후 표면 촬영 검사 + 표본(전체 수확량의 5%) 대상 48시간 후 경도/절단 검사 병행 — 즉시 표면 촬영만으로는 잠재적 내상(지연성 멍) 검출 불가 |
| **숙성도 판별 정확도** | - | **90% 이상** | `(정확 판별된 숙성 단계 수 / 실제 숙성 단계 총 수) × 100` — 인접 단계 경계에서는 숙련 인력 간 판정 일치도(약 85~90%)가 상한선임을 감안 |
| **파지·절단 결합 포즈 추정 성공률** | - | **85% 이상** | Valid 결합 포즈(과실중심+Pedicel축, 충돌 회피 가능) 추론 성공 건수 / 비전 요청 건수 |
| **Pedicel 절단 위치 정밀도** | - | **±2mm 이내** | 절단창(5~10mm, 폭 5mm) 대비 여유를 두기 위해 ±5mm가 아닌 ±2mm로 설정. 근접 정밀 카메라(4장) 2단 촬영 기반 추정, 검증은 수확 과실의 잔류 Pedicel 길이 캘리퍼 표본계측으로 수행(레이저트래커는 식물 절단면 계측에 부적합하여 사용하지 않음) |
| **개별 과실 평균 사이클타임** | 숙련 작업자 3~4초/개 | **15초/개 이하** | 비전 인식 시작부터 트레이 적재 완료까지, 재시도(최대 2회) 포함 기대값. 문헌상 유사 연성과실 수확 로봇(7~15초/개) 수준을 목표로 함 |
| **일일 수확량** | 작업자 1인 기준 | MVP~Phase 1: 주간 10시간 가동 기준 인력 1인 1일 물량 확보<br>Phase 2: 야간 조명 자동화 도입 후 20시간 연속가동으로 확대 | 등급별 적재 트레이 수량 × 평균 중량 (가동 시간대는 로드맵 단계에 따름, 7장 참조) |
| **MTBF (평균 무고장 시간)** | - | **150시간 이상** (MTTR 목표 8시간 이내) | 총 가동시간 / (하드웨어 + SW 통합 장애 발생 횟수). 온실의 고습도·분진 환경을 고려해 산업용 대비 보수적으로 설정 |
| **설비 가동률 (Availability)** | - | **90% 이상** | `MTBF / (MTBF + MTTR)` 기준, 상기 MTBF 150h·MTTR 8h 목표 시 산술적으로 약 94.9% 확보되어 목표치에 여유 마진 존재 |
| **수확 인력 감축률** | 라인당 수확 인력 2.5명(2~3명) | **80% 이상** | `(As-Is 인력 − To-Be 인력) / As-Is 인력 × 100` = (2.5명 − 0.5명) / 2.5명 × 100 |

## 5. 기능 범위 (Scope & Out of Scope)

### 5.1 범위 내 (In-Scope)

#### 1) AI 비전 기반 숙성도 판별 및 인식 시스템
- RGB-D + 컬러/다분광 카메라 기반 트러스 촬영, 개별 과실 인스턴스 세그멘테이션.
- 적색도/반사율 기반 표준 6단계 숙성도 분류(그린~레드) 및 목표 수확 단계(라이트레드~레드) 필터링, 과숙(수확 제외) 자동 배제.
- 열과·병해충 변색·기형과 등 비정상 과실을 별도 예외 클래스로 필터링(정밀 질병 진단은 5.2절 Out-of-Scope).
- 비전 신뢰도(Confidence Score) 기반 분기:
  - 신뢰도 90% 이상: 자동 수확 수행.
  - 신뢰도 미달 시: 자동 재촬영(최대 2회) → 지속 미달 시 해당 과실 스킵 및 차기 순회 대상으로 기록(3장 "1회 순회 미탐지율"에 집계).

#### 2) 카메라-로봇 좌표계 자동 Calibration
- Hand-Eye Calibration (Eye-in-Hand) 초기/주기적 교정.
- 레일 이동 및 수직 리프트 축 이동에 따른 구간별 위치 오프셋 자동 보정.
- 카메라 좌표계 ↔ 로봇 베이스 프레임 TF(Transform) 실시간 변환.

#### 3) 파지·절단 결합 계획 및 실행 (Grasp-Cut Planning & Execution)
- 과실 중심 3D 위치 및 Pedicel 축 방향 기반 **단일 결합 6-DOF 접근 포즈** 자동 추정(그리퍼-절단날 고정 오프셋 적용, 파지점과 절단점을 독립적으로 추정하지 않음).
- MoveIt2 기반 잎/줄기/인접 과실 회피 궤적 생성.
- 압력/슬립 센서 기반 실시간 grip force 제어(손상 방지 임계값 이내 유지).
- 가위형 엔드이펙터로 동일 접근축 상에서 Pedicel 절단, 절단 실패 시 비틀어 따기(Twist-pick) 대체 로직 수행.
- 절단/파지 실패 시 2회 자동 재시도, 최종 실패 시 스킵 및 로그 기록(모주 손상 방지 우선).
- 절단날 정기 소독(트러스 전환 시마다) 및 마모/오염 감지 — 칼날을 통한 식물 병원체(ToBRFV 등 바이러스) 전파 방지.

#### 4) 수확 미션 관리 및 등급별 트레이 적재
- 미션 데이터 관리: `harvest_mission_id`, `truss_id`, `fruit_id`, `ripeness_grade`, `status`.
- 숙성 등급 및 크기 기준 트레이 자동 분류 적재.
- 손상·예외(열과/변색/기형과) 검출 시 별도 폐기/가공용 트레이로 분리.

#### 5) 이동 플랫폼(레일/AMR) 연동
- 레일 구간별 위치 이동 및 수직 리프트 축 정지 제어 신호 연동.
- 구간 이동 완료 후 잔여 미수확 과실 카운트 및 위치 기록.

#### 6) 학습 데이터 파이프라인 및 MLOps
- 신규 품종/재배 환경 등록 시 소량 샘플 기반 Fine-tuning.
- 손상/절단 실패 케이스 자동 수집 큐 구축 및 MLflow 기반 모델 버전 관리.

#### 7) 인터페이스, 데이터 모델 및 보안
- REST / gRPC API 제공 (`/vision/ripeness`, `/harvest-mission`, `/tray/place`, `/truss/status`).
- 타임아웃 규칙: 비전 추론 5초, 파지+절단 실행 20초(단계별 상한, 재시도 포함 기대 사이클타임은 3장 참조), 트러스 전체 처리 8분 이내.
- 보안: RBAC(역할 기반 접근 제어), 작업자 얼굴 블러링 처리(수집 이미지 내 개인정보 비식별화 전처리 포함), 온실 환경데이터 암호화 전송.
- Edge AI 오프라인 작동: 네트워크 단절 시 Edge PC에서 추론/제어 수행 후 복구 시 백엔드 일괄 동기화.

#### 8) 물리적 안전 및 관리 대시보드
- ISO 15066 협동로봇 안전 규격 준수 (속도 제한, 작업자 접근 감지 시 감속/정지).
- 실시간 수확량, 손상률, 숙성 지도(Ripeness Map), 미탐지율/미수확율 시각화 대시보드 제공.

### 5.2 범위 외 (Out-of-Scope)
1. **범용 하드웨어 자체 제작**: 로봇팔, 센서, 이동 플랫폼 등 범용 상용 부품의 직접 기계 설계/제조는 제외(상용 제품 활용). **단, 방울토마토 전용 복합 엔드이펙터(소프트그리퍼+절단 모듈)는 대상 크기(15~30mm)에 맞는 상용품이 존재하지 않아 자체 설계·제작을 In-Scope로 포함**(4장, 5.1-3항 참조).
2. **재배 환경 자체 제어**: 관수/온습도/양액 제어 (기존 스마트팜 IoT 설비와의 연동에 한함, 직접 제어 로직 개발 제외).
3. **작물 질병 정밀 진단 및 방제 처방**: 병해충 종류 식별, 방제 약제 추천 등 정밀 진단 기능은 범위 외. (단, 과실 표면의 병해충 유래 변색·오염을 숙성도 판별 오탐 방지 차원에서 필터링하는 로직은 5.1-1항에 따라 범위 내에 포함됨.)
4. **완전 자율 온실 내비게이션**: 로봇 이동은 사전 정의된 레일/트랙 기반에 한하며, 자유 주행 AMR 자율주행 알고리즘 자체 개발 제외.
5. **다품종 작물 확장**: 방울토마토 외 타 작물(대추방울토마토, 파프리카 등) 수확 알고리즘은 Phase 2 이후 별도 검토.
6. **수확 후 후숙/저장 물류**: 트레이 적재 이후의 저장, 후숙, 출하 물류 공정은 범위 외.
7. **완전 무인 야간 운영**: MVP~Phase 1은 주간 운영 기준이며, 야간 조명 자동화 기반 24시간 운영은 Phase 2로 이관(3장·8장의 24시간 관련 목표치는 모두 Phase 2 기준임을 명시).

### 5.3 주요 가정 사항 (Assumptions)
- 온실은 표준 하이와이어 유인재배 방식(수직 유인, 일정 간격 통로)을 따름.
- 로봇/AMR 이동을 위한 레일 또는 통로 폭(800~1,200mm)이 사전 확보됨.
- 대상 방울토마토 품종은 표준 크기/무게 범위(지름 15~30mm, 개당 10~20g) 내에 있음(품종별 편차는 현장 조사로 재확인).
- 온실 내 유·무선 통신 인프라(Wi-Fi/유선)가 사전 구축되어 있음.
- 조명은 자연광 기반이며, 심각한 역광/직사광은 차광막 등 기존 온실 설비로 일부 완화됨.
- 로봇 제조사가 정식 ROS2 드라이버 및 MoveIt2 설정 파일을 제공함.
- **커스텀 엔드이펙터(그리퍼+절단 모듈) 설계·제작에 필요한 리드타임(3~6개월)이 프로젝트 일정에 사전 반영됨.**
- **수확기(과실이 실제로 결실·숙성 중인 생육 시기)에 현장 접근이 가능하여 실물 데이터 수집 및 실증이 가능함.**

## 6. 리스크 관리 및 완화 방안 (Risks & Mitigation)

| 리스크 항목 | 영향도 | 발생 가능성 | 대응 및 완화 방안 (Mitigation Strategy) |

| **잎/줄기에 의한 과실 가림(Occlusion)** | 높음 | 높음 | • 다중 시점 재촬영 및 Occlusion-aware Segmentation 모델 강화<br>• 가림 심할 시 해당 과실 스킵 후 차기 순회 대상 기록(3장 "1회 순회 미탐지율"로 관리) |

| **수분(受粉) 부족에 의한 기형과(Catface)** | 낮음 | 낮음 | • 기형과 형상 인식 후 파지 대상에서 제외<br>• 수분 상태 모니터링 데이터 연계 |

| **온실 환경(고습도·분진·결로) 센서 오작동** | 중간 | 중간 | • 방수방진(IP65 이상) 인클로저 적용<br>• 정기 렌즈 클리닝 및 결로 방지 히터 내장 |

## 7. 릴리즈 단계별 로드맵 (Release Roadmap)

```
[MVP Phase (4~6개월)]  ->  [Phase 1 (4~6개월)]  ->  [Phase 2 (4~6개월)]
데이터셋/Isaac Sim 검증 +          비정형 클러스터 대응 &         다중 구역 확장 & 야간 운영 &
단일 레일 실물 시험 수확           등급 자동화 & 결합 포즈 고도화    타작물 PoC & 트러스 단위 수확 검토
```

### 7.1 MVP (4~6개월)
- **범위**: Pedicel 결합 포즈 라벨링 툴 자체 개발 및 오프라인 데이터셋 구축, Isaac Sim 기반 사전 검증, 커스텀 엔드이펙터(그리퍼+절단 모듈) 시제품 제작(리드타임 반영). 단일 레일 구간·상대적으로 정형화된 트러스 배치를 대상으로 기본 숙성 과실 인식 및 시제품 엔드이펙터 기반 실물 시험 수확.
- **핵심 산출물**: Basic 비전 인식 파이프라인(숙성도 3단계 간소화), 결합 포즈 커스텀 모델 v0, ROS2 로봇 제어 모듈, 기본 수확 미션 API, 대시보드 UI.

### 7.2 Phase 1 (4~6개월)
- **범위**: 잎에 의한 가림 등 비정형 클러스터 대응, 결합 포즈 추정 정밀도(±2mm) 고도화, 숙성 등급별(표준 6단계) 자동 분류 적재.
- **핵심 산출물**: Occlusion-aware Segmentation, MLOps 기반 손상/실패 데이터 수집 시스템, 근접 정밀 카메라(D405) 2단 촬영 파이프라인.

### 7.3 Phase 2 (4~6개월)
- **범위**: 다중 레일/온실 구역 확장, 야간 조명 자동화 기반 24시간 연속 운영 도입, 병해충 시각 모니터링 연계 검토, 타작물(파프리카 등) 확장 PoC, **트러스(화방) 단위 일괄 수확 아키텍처 대안 Feasibility 검토**(개체 단위 대비 처리량·등급분류 트레이드오프 비교).
- **핵심 산출물**: 다구역 스케줄링 오케스트레이터, 야간 조명 제어 연동 모듈, 초분광 기반 Brix 추정 PoC, 트러스 단위 수확 Feasibility 리포트.

## 8. 정량적 ROI 요약 (ROI Summary)

> **"AI 비전 기반 숙성도 자동 판별과 파지-절단 결합 포즈 추정을 통해, MVP~Phase 1의 주간 운영만으로도 수확 성공률 85% 이상을 확보하고 과실 손상률을 3%에서 5% 이하(Phase 2 목표 3% 이하)로 관리하며, Phase 2의 야간 조명 자동화 도입 시 24시간 연속 순회 수확으로 최적 수확 타이밍을 놓치는 로스를 최소화한다. 이를 통해 라인당 수확 인력을 2.5명에서 0.5명 이내로 절감(감축률 80% 이상)하고, 등급별 자동 분류 적재로 후속 선별 공정 비용을 절감함으로써, 총 수확 공정 운용 비용을 유의미하게 절감한다."**
