# [PRD] AI 비전 기반 비정형 물체 파지 및 적재 자동화 로봇팔 Pick & Place 시스템

---

## 1. 개요 및 문제 정의 (Overview & Problem Definition)

### 1.1 배경 및 작성 목적
본 문서(PRD)는 AI 비전 기술 및 6-DOF 파지 위치 추정(Grasp Pose Estimation) 알고리즘을 활용하여, 비정형 및 무질서하게 적재된 물체를 자동으로 인식·파지·적재하는 **협동/산업용 로봇팔 Pick & Place 시스템**의 제품 요구사항을 정의합니다.

### 1.2 기존 공정의 문제점
1. **인력 의존형 반복 작업의 한계**
   - 동일한 피킹/적재 동작을 일 수천 회 반복함에 따라 작업자 피로도 증대, 누적통증장애(CTD) 발생 및 이직률 급증.
2. **정형 지그(Jig) 및 트레이 의존성**
   - 기존 고정식 자동화는 정해진 위치와 각도로 정렬된 물체만 취급 가능하여, SKU(다품종) 확장 시 개별 지그/픽스처 제작 및 교체 비용이 지속 발생.
3. **비정형/무질서 적재(Bin Picking) 대응 불가**
   - 빈(Bin) 또는 박스 내 혼재·겹침·뒤집힘 상태의 부품에 대해 기존 2D 비전 시스템으로는 3차원 파지점 계산 불가능.
4. **소량 다품종 전환 및 티칭 비용 과다**
   - 신규 제품 투입 시 로봇 티칭(Teaching) 및 재프로그래밍에 오랜 시간(수일 소요)이 필요하여 중소규모 다품종 생산라인 적용 저해.

### 1.3 Target Audience 및 적용 분야

| 대상 구분 | 도입/적용 시점 | 주요 기대 효과 |
| :--- | :--- | :--- |
| **중소 제조업체 생산 담당자** | • 연간 픽킹 건수 50만 건 이상<br>• 인력 채용/유지 난항<br>• SKU 50개 이상 다품종 공정 | • 단순 반복 작업 인력 절감<br>• 신규 SKU 등록 및 티칭 시간 극대화 단축 |

## 2. 사용자 시나리오 및 워크플로우 (User Scenarios & Workflow)

### 2.1 핵심 공정 프로세스 (Core Flow)
```
[1. 비전 촬영/인식] -> [2. 6D Pose/파지점 추정] -> [3. 충돌회피 궤적생성] -> [4. Pick 실행] -> [5. 이동 & Pose 보정] -> [6. Place 실행] -> [7. 결과 검증 및 잔류 확인]
```

1. **Pick 단계**: RGB-D 카메라 촬영 → 물체 탐지/세그멘테이션 → GraspNet 기반 6-DOF 파지점 추정 → 로봇팔 접근 궤적 생성 → 파지(Gripping) → 파지 상태 검증 및 들어올림.
2. **이동 단계**: 지정 안전 높이(Safe Z-Height) 상승 → 간섭 및 충돌 회피 경로(MoveIt2) 탐색 → 목표 적재 위치 이동.
3. **Place 단계**: 적재 구역 비전 인식/위치 보정 → 정밀 하강 → 엔드이펙터 파지 해제 → 로봇팔 안전 위치 복귀.
4. **검증 단계**: 공급 빈(Bin) 내 잔류 물체 촬영 → 픽 성공 여부 판단 → 실패 시 재시도/에스컬레이션 트리거.

| 사용자 역할 | 주요 작업 상황 | 시스템 사용 행동 (Action) | 최종 산출 결과 (Result) |
| :--- | :--- | :--- | :--- |
| **라인 운영자** | 신규 SKU 제품 생산 투입 | 5장 이하 샘플 이미지 촬영 및 Few-shot 티칭 가이드 실행 | 1시간 이내 신규 SKU 인식 및 라인 투입 준비 완료 |
| **생산 엔지니어** | 비정형 무질서 부품 Bin 투입 | 시스템 시작 명령 발행 및 자동 비전 인식/Grasp Planning 모니터링 | 무질서 겹침 더미에서도 최적 파지점 추론 후 안정적 픽킹 |

| **창고 관리자** | AGV 연계 팔레타이징/하역 | 픽킹 완료 후 VDA 5050/MQTT 기반 AGV 하역 미션 발행 | 로봇-AGV 간 상호 시그널 교환을 통한 하역 자동화 |
| **경영진/임원** | 월간 생산성 및 자동화 효과 검토 | 대시보드 내 설비 종합 효율(OEE), 가동률, ROI 리포트 조회 | 데이터 기반 ROI 측정 및 추가 자동화 투자 의사결정 |

## 3. 성공 지표 (Key Performance Indicators, KPI)

| KPI 항목 | 현재 기준 (As-Is) | 목표치 (To-Be) | 측정 방법 및 조건 |
| :--- | :--- | :--- | :--- |
| **픽킹 성공률 (Pick Success Rate)** | 숙련 작업자 95% | **97% 이상** | `(성공 픽 건수 / 총 픽 시도 건수) × 100` |
| **사이클 타임 (Tact Time)** | 숙련 작업자 6초/건 | **4초/건 이하** | 비전 인식 시작부터 Place 완료 후 복귀 시점까지의 평균 |
| **비전 인식 정확도** | - | **95% 이상** | `(정확히 탐지된 물체 수 / 실제 물체 총 수) × 100` |
| **파지점 추정 성공률** | - | **90% 이상** | Valid Grasp Pose 추론 성공 건수 / 비전 요청 건수 |
| **하중/무게 측정이탈 오차** | ±5g | **±1g 이내** | 엔드이펙터 내장 로드셀/압력센서 기준 정밀 측정 |

| **설비 가동률 (Availability)** | 70% | **90% 이상** | `(실제 가동 시간 / 계획된 총 가동 시간) × 100` |
| **드롭/물체 손상률** | 1% | **0.1% 이하** | `(파지 이동 중 낙하/손상 건수 / 총 픽 건수) × 100` |

## 5. 기능 범위 (Scope & Out of Scope)

### 5.1 범위 내 (In-Scope)

#### 1) AI 비전 기반 인식 시스템
- RGB-D 카메라 기반 물체 탐지, 세그멘테이션 및 Bin Picking 무질서 환경 인식.
- 겹침/뒤집힘 상태 물체에 대한 6D Pose 추정 및 파지 가능 구역 추출.
- 비전 신뢰도(Confidence Score) 기반 분기:
  - 신뢰도 95% 이상: 자동 픽 수행.
  - 신뢰도 미달 시: 자동 재촬영(최대 2회) → 지속 미달 시 Human-in-the-loop(작업자 승인) 모드로 전환.

#### 2) 카메라-로봇 좌표계 자동 Calibration
- Hand-Eye Calibration (Eye-in-Hand 및 Eye-to-Hand) 초기/주기적 교정.
- ChArUco / Grid 보드 기반 Extrinsic 파라미터 자동 산출.
- 카메라 좌표계 ↔ 로봇 베이스 프레임 TF(Transform) 실시간 변환.
- Tool Changer 교체 및 외부 충격 감지 시 툴-카메라 Offset 자동 재캘리브레이션.

#### 3) 파지 계획 및 실행 (Grasp Planning & Execution)
- GraspNet / AnyGrasp 기반 6-DOF 파지 위치 및 접근 각도 추정.
- MoveIt2 기반 실시간 충돌 회피 궤적 생성 및 안전 높이 경로 설정.
- 그리퍼 압력/슬립(Slip) 감지를 통한 파지 성공 여부 검증.
- 이동 중 물체 드롭 감지 시 2회 자동 재시도, 최종 실패 시 시스템 알림 및 에스컬레이션.

#### 4) Pick & Place 미션 관리 및 멀티 그리퍼 호환
- 미션 데이터 관리: `pick_mission_id`, `source_bin`, `target_zone`, `status`.
- ISO 9409-1 표준 매카니컬 인터페이스 기반 자동 Tool Changer 연동 (교체 시간 10초 이내).
- RFID/바코드 기반 엔드이펙터 ID 자동 식별 및 파지 파라미터 적용.

#### 5) 로봇-AGV/컨베이어 핸드오버 및 연동
- VDA 5050 / MQTT 프로토콜 기반 AGV 하역 시그널 연동 (`pickup_confirmation`, `placement_ack`).
- 하역 후 스마트 카메라를 활용한 빈 내 잔류 물체 자동 확인.

#### 6) Few-Shot 티칭 및 MLOps 파이프라인
- 5장 이하 샘플 이미지로 신규 SKU 등록 및 몇 분 내 Auto Fine-tuning.
- failure-case 자동 수집 큐 구축 및 MLflow 기반 모델 버전 관리.

#### 7) 인터페이스, 데이터 모델 및 보안
- REST / gRPC API 제공 (`/vision/detect`, `/pick-mission`, `/place-mission`, `/handover/agv`, `/teach/new-sku`).
- 타임아웃 규칙: 비전 추론 5초, 파지 30초, 전체 픽 5분, 하드웨어 비정상 10분.
- 보안: RBAC(역할 기반 접근 제어), SROS2 통신 암호화, 타임스탬프 기반 Replay Attack 방지, 작업자 얼굴 블러링 처리.
- Edge AI 오프라인 작동: 네트워크 단절 시 Edge PC에서 추론/제어 수행 후 복구 시 백엔드 일괄 동기화.

#### 8) 물리적 안전 및 관리 대시보드
- ISO 15066 협동로봇 안전 규격 준수 (속도 제한, 안전 펜스/라이트 커튼/PIR 센서 연동).
- 실시간 픽 성공률, MTBF, 가동률, 손상률 시각화 대시보드 제공.

### 5.2 범위 외 (Out-of-Scope)
1. **하드웨어 자체 제작**: 로봇팔, 엔드이펙터, 센서 등의 직접 기계 설계/제조 (상용 제품 활용).
2. **제어기 펌웨어 개발**: 모터 드라이브, 로봇 컨트롤러 Low-level 펌웨어 개발 (제조사 SDK 활용).
3. **독자 역학/모션 엔진 개발**: 로봇 Kinematics 엔진 직접 개발 (ROS2 / MoveIt2 활용).
4. **AGV/AMR 자율주행 알고리즘**: AGV 자체의 모빌리티/주행 제어 (VDA 5050 인터페이스 연동에 한함).
5. **물리 인프라 공사**: 팬스 설치, 공압 파이프, 전력 배선 및 작업장 인프라 설치 작업.
6. **PLC/SCADA 물리적 라인 개조**: MVP 단계에서는 API/게이트웨이 연동에 한하며 직접적인 PLC HW 개조 제외 (Phase 2로 이관).
7. **양팔 로봇(Bi-manual Arm) 협업**: 1단계는 단일 로봇팔 단독 작업으로 한정.

---

### 5.3 주요 가정 사항 (Assumptions)
- 로봇팔, 센서 및 Edge 컴퓨팅 하드웨어는 사전 구비 또는 지정 표준 사양으로 설치됨.
- 로봇 제조사가 정식 ROS2 드라이버 및 MoveIt2 설정 파일을 제공함.
- 대상 물체는 로봇팔 최대 가용 하중(예: 3kg~5kg) 이내이며, 엔드이펙터로 파지 가능한 표면 특성을 가짐.
- 작업 구역의 조명 조건은 비전 인식에 심각한 장애를 유발하지 않는 일정 범위 내로 제어됨.

## 7. 릴리즈 단계별 로드맵 (Release Roadmap)

```
[MVP Phase (2~3개월)]  ->  [Phase 1 (3~4개월)]  ->  [Phase 2 (3~4개월)]
정형 물체 & 기본 P&P        비정형 Bin Picking & MLOps       AGV연동 & OPC-UA & 강화학습
```

### 7.1 MVP (2~3개월)
- **범위**: 정형 물체 대상 단일 픽 & 플레이스, 1종 그리퍼 적용, 단일 작업 영역.
- **핵심 산출물**: Basic 비전 인식 파이프라인, ROS2 로봇 제어 모듈, 기본 Pick Mission API, 대시보드 UI.

### 7.2 Phase 1 (3~4개월)
- **범위**: 비정형 무질서 적재(Bin Picking) 대응, 이종 그리퍼 자동 교체(Tool Changer), Few-shot 티칭.
- **핵심 산출물**: GraspNet 6D Pose 모델 연동, Auto Fine-tuning 파이프라인, MLOps 기반 실패 데이터 수집 시스템.

### 7.3 Phase 2 (3~4개월)
- **범위**: AGV/컨베이어 연동, PLC/SCADA(OPC-UA/Profinet) 공정 통합, 강화학습 기반 Sim2Real, 양팔 협업 검토.
- **핵심 산출물**: VDA 5050 핸드오버 게이트웨이, OPC-UA 통신 모듈, Isaac Sim RL 훈련 환경 및 양팔 협업 PoC.
